## 6. 빠른 재개용 체크 명령

(환경에 맞게 경로/명령 래퍼 조정)

- 차이 확인:
  - diff -rq backend/app ref-source-code/backend/app
  - diff -rq frontend ref-source-code/frontend

- 프론트 빌드:
  - cd frontend && npm install && npm run build

- 오프라인 Alembic SQL 재생성:
  - cd backend
  - python -m alembic upgrade head --sql > ../markdown/alembic_upgrade_head_offline_retry.sql

- 온라인 Alembic 실행(실DB 연결 가능 시):
  - cd backend
  - python -m alembic current
  - python -m alembic upgrade head
